# 🏥 Hospital System Oficial

Sistema de gestão hospitalar desenvolvido em Java, projetado para facilitar a administração de consultas, médicos e especialidades.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Java
* **IDE:** IntelliJ IDEA
* **Interface Gráfica:** Java Swing
* **Controlo de Versão:** Git / GitHub

---

## 📁 Estrutura do Projeto

* `src/` - Contém todo o código-fonte Java (DAOs, Telas, Conexão com Banco de Dados).
* `.gitignore` - Ficheiros ignorados pelo Git.
